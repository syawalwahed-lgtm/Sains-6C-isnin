# Misi Angkasa Sains Tahun 6 — Gerhana & Galaksi

Laman pembelajaran interaktif Bahasa Melayu untuk murid Tahun 6. Fail utama ialah `index.html`; tiada pemasangan atau pustaka luar diperlukan.

## Cara guna
1. Buka `index.html` menggunakan Chrome, Edge, Safari atau Firefox.
2. Masukkan nama murid dan tekan **Mula Misi Pembelajaran**.
3. Aktifkan **Bunyi: ON** untuk kesan bunyi ringkas dan bacaan suara melalui Text-to-Speech peranti (jika suara Bahasa Melayu tersedia).
4. Baca nota, buka pautan carian video YouTube, kemudian jawab 30 soalan.

## Terbitkan percuma menggunakan GitHub Pages
1. Log masuk ke GitHub dan cipta repository baharu, contohnya `misi-angkasa-tahun6`.
2. Muat naik `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Di bahagian Build and deployment, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, kemudian **Save**.
5. Tunggu proses penerbitan selesai. GitHub akan memaparkan URL Pages dalam Settings → Pages, lazimnya `https://NAMA-PENGGUNA.github.io/misi-angkasa-tahun6/`.

## Penyesuaian kurikulum
Bahan ini menggunakan skop umum Gerhana dan Galaksi. Sebelum digunakan sebagai bahan rasmi, guru perlu mengesahkan tajuk unit serta nombor Standard Kandungan (SK) dan Standard Pembelajaran (SP) berdasarkan DSKP, RPT sekolah dan edisi buku teks yang digunakan. Pautan YouTube ialah pautan carian, bukan pengesahan video tertentu.

## Ciri
- Reka bentuk responsif untuk telefon, tablet dan komputer.
- Latar angkasa beranimasi CSS dan grafik emoji.
- 30 soalan aneka pilihan, skor, bintang, cuba semula jika salah dan paparan kemenangan.
- Butang bunyi mengaktifkan nada dan suara peranti jika disokong.
- Tiada data murid dihantar atau disimpan ke pelayan; nama hanya digunakan pada sesi semasa.
